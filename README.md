A pragmatic Node.js implementation of the famous Spring PetClinic sample application.

## Environment Setup
1. Ensure you have **Node.js** (v16+) installed.

## Features
- Full CRUD for Owners and Pets.
- Visit management.
- Veterinarian listings with pagination.
- I18n support (English, German, Spanish).
- Server-side rendering with EJS.
